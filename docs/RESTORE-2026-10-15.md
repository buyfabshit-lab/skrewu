## Reconnected configuration

The Supabase project URL and publishable key are configured on both Netlify projects. Private credentials are intentionally not stored in Git.

The following secrets must remain configured only in Netlify for their related features to operate:

- `SUPABASE_SERVICE_ROLE_KEY`
- `STRIPE_SECRET_KEY`
- `STRIPE_WEBHOOK_SECRET`
- `SHOPIFY_WEBHOOK_SECRET`
- Any feature-specific Shopify, TikTok, or AI credentials

Never commit secret values to this repository.
